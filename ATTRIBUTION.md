# Attribution

Files of this repository that come from elsewhere, with their authors, sources and licences. `cargo xtask assets`
checks that every file of `assets/`, and every file that `cargo xtask unicode` writes from the Unicode Character
Database, has its line here, and that every file named here exists.

The images of `docs/images/` and the files of `design/` are the project's own work; they get their lines here with the
new logo.
