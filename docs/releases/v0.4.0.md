## Install on Windows

`labcraft-0.4.0-windows-x64.msi` (the same file as `labcraft-windows-x64.msi`) installs LabCraft for every user of the machine, in `C:\Program Files\LabCraft`:
the IDE `labcraft` in the Start menu, and `labcraft-cli` in the `PATH`, so that a terminal opened after the install,
or an AI agent started after it, finds it by its name; a terminal open during the install keeps its old `PATH`. A double
click on a `.lcf` or a `.lct` file opens it in LabCraft, with its project; Win+R `labcraft` starts the IDE. It holds the same files as the zip archive. A later version installed over it
replaces it; *Settings > Apps > Installed apps* removes it.

**The installer is not signed yet.** Windows says so twice:

- When it opens, SmartScreen may show "Windows protected your PC": choose *More info*, then *Run anyway*.
- Windows then asks to allow an app from an unknown publisher to make changes to the device: choose *Yes*. Installing
  for every user needs an administrator.

The zip archive needs no install: unzip it anywhere, and run the programs from its folder.
